# Aula 1: Notas e Estratégias de Avaliação

**Data:** 10/09

---

## Descrição

Nesta aula, foram apresentadas as notas e estratégias de avaliação que orientarão o desenvolvimento do portfólio e dos projetos ao longo do curso. A ênfase foi dada à preparação para testes práticos e à construção de uma aplicação web funcional, seguindo boas práticas de desenvolvimento.

---

## Avaliação

A avaliação desta etapa será composta pelos seguintes itens:

1. **Teste de Codificação Ao Vivo**  
   Exame disponibilizado 48 horas antes das datas agendadas.  
   **Datas:** 12/11 e 12/18 _(data posteriormente alterada)_

2. **Envio do Portfólio**  
   **Data limite:** 02/12

3. **Atividade Prática com Requisitos**  
   **Data limite:** 01/22

---

## Atividade Final

A atividade final deverá conter:

- Ao menos uma API desenvolvida.
- Um endpoint documentado com parâmetros de entrada e saída.
- Código limpo e bem estruturado.
- Plena funcionalidade da aplicação.
- Validações necessárias para a entrada de dados e tratamento de erros.
- **Bônus:** Caso a aplicação seja elástica ou escalável.
- Integração com um banco de dados.
- Testes realizados com base na documentação do projeto.

---

## Pontos Importantes para a Próxima Aula

- Criar um ambiente virtual Python utilizando o `venv`.
- Aprender a instalar pacotes Python (serão instalados durante a aula).
- Gerar um arquivo `requirements.txt` listando todas as dependências utilizadas (similar ao `package.json`).
- Garantir que o Python 3.11 esteja instalado na máquina.
- Familiarizar-se com o uso do Linux.

---

## Melhores Práticas

- **Organização do Código:**  
  Evitar colocar o código dentro da pasta do ambiente virtual.

- **Desenvolvimento Web:**  
  Priorizar a criação de aplicações web, ao invés de soluções locais, para facilitar a escalabilidade e a manutenção do projeto.

---

## Conclusão

Esta aula estabelece as bases para a avaliação do curso e define os requisitos que serão cobrados na atividade final. A atenção às boas práticas e a organização do ambiente de desenvolvimento são fundamentais para o sucesso nas próximas etapas.
