Introdução às Aplicações Web com Flask

Nesta aula, exploramos os conceitos fundamentais de requests (solicitações) e responses (respostas) entre cliente e servidor, que são a base para a criação de aplicações web dinâmicas com Flask.

Iniciando o Servidor Flask

Você pode iniciar o servidor de duas formas:

  1. Pelo terminal com o comando: 
    flask run --debug
  2. Executando diretamente o script (desde que o app esteja configurado com app.run(debug=True, host='0.0.0.0')): 
    python app.py

O modo debug reinicia o servidor automaticamente sempre que uma alteração é detectada no código.

Criando uma Rota Básica

Para criar uma rota simples, utilize o decorador @app.get: 

@app.get("/")
def home():
    return {"message": "Hello, Flask!"}

Para definir uma rota que aceite múltiplos métodos, use o decorador @app.route com o parâmetro methods: 

from flask import request

@app.route("/data", methods=["GET", "POST"])
def data_handler():
    if request.method == "POST":
        # Processa os dados enviados
        pass
    else:
        # Retorna os dados
        pass
