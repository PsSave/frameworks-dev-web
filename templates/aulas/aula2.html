Configuração do Ambiente Virtual e Instalação do Flask

Passos Essenciais:

  1. Criar o Ambiente Virtual: 
    python -m venv meu_ambiente
  2. Permitir Ambientes Virtuais (no PowerShell, apenas uma vez): 
    Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
  3. Ativar o Ambiente: 
    meu_ambiente\Scripts\activate
  4. Instalar o Flask: 
    pip install flask

Padronização e Organização do Código

  • Arquivos HTML devem estar na pasta templates.
  • Utilize código limpo com nomes significativos (em inglês).
  • Siga a convenção snake_case para variáveis (sem acentos ou caracteres especiais).
