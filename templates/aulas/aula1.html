Notas e Estratégias de Avaliação

Avaliação:

  1. Teste de Codificação Ao Vivo (Exame disponibilizado 48 horas antes) - (12/11 e 12/18) (data posteriormente alterada)
  2. Envio do Portfólio (02/12)
  3. Atividade Prática com Requisitos (01/22)

A atividade final deve conter:

  • Ao menos uma API desenvolvida;
  • Um endpoint documentado com parâmetros de entrada e saída;
  • Código limpo e bem estruturado;
  • Plena funcionalidade;
  • Validações necessárias para entrada de dados e tratamento de erros;
  • Bônus: Caso a aplicação seja elástica ou escalável;
  • Integração com um banco de dados;
  • Testes baseados na documentação do projeto.

Pontos importantes para a próxima aula:

  • Criar um ambiente virtual Python usando venv;
  • Aprender a instalar pacotes Python (serão instalados durante a aula);
  • Gerar um arquivo requirements.txt listando as dependências (similar ao package.json);
  • Assegurar que o Python 3.11 esteja instalado;
  • Familiarizar-se com o uso do Linux.

Melhores Práticas:

  • Evite colocar o código dentro da pasta do ambiente virtual;
  • Priorize o desenvolvimento de aplicações web ao invés de soluções locais.
