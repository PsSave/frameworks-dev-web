Criando um Novo Ambiente Virtual e Desenvolvendo Código

Sempre importe Flask ao criar um novo ambiente virtual: from flask import Flask

Conceitos-Chave:

  • Cada requisição web segue o padrão RR (Request and Response).
  • O ambiente web é reativo – ele atua somente quando há uma requisição.
  • Flask permite que o código Python escute requisições e responda adequadamente.
  • Primeiro, a requisição chega ao Flask; em seguida, o Python a processa e retorna uma resposta.

O primeiro passo é criar a aplicação Flask.

A variável que representa a aplicação pode ter qualquer nome, mas normalmente é definida no app.py.

Para atualizar automaticamente o servidor ao modificar o código: app.run(debug=True)

Para alterar a porta padrão: app.run(debug=True, port=XXXX)

Para tornar a aplicação acessível na rede local: app.run(debug=True, port=XXXX, host='0.0.0.0')

Para que uma aplicação web seja reativa, ela precisa de rotas. Rotas devem estar vinculadas a funções que definem a resposta.

Exemplo de criação de uma rota:
