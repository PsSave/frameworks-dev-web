# Portfólio - Framework para Desenvolvimento Web

Este repositório reúne um portfólio que documenta as aulas, projetos e atividades desenvolvidas na disciplina **Framework para Desenvolvimento Web**. Durante o segundo semestre de 2024, no IFMS - Câmpus Três Lagoas, sob a orientação do professor **Alex Fernando de Araújo**.

---

## Tecnologias Utilizadas

- **Python 3** – Linguagem utilizada para o desenvolvimento.
- **Flask** – Microframework web para criação de aplicações dinâmicas.
- **HTML5, CSS3 e JavaScript** – Para a estrutura, estilo (com tema dark) e interatividade das páginas.

---

# Como Executar o Projeto

Siga os passos abaixo para clonar e executar o projeto:

1. **Clone o repositório:**

```bash
   git clone https://github.com/PsSave/frameworks-dev-web.git
```

2. **Acesse o repositório no seu computador:**

```bash
  cd frameworks-dev-web
```

3. **Crie um ambiente virtual:**

```bash
  python3 -m venv venv
```

4. **Ative o ambiente virtual:**

- No Windows:
  ```bash
  venv\Scripts\activate
  ```
- No macOS/Linux:
  ```bash
  source venv/bin/activate
  ```

5. **Instale as dependências:**

```bash
  pip install -r requirements.txt
```

6. **Execute a aplicação:**

```bash
  flask run
```

7. **Acesse a aplicação no navegador:**

Abra o navegador e vá para `http://127.0.0.1:5000`

# Estrutura do Projeto

- **aulas/**: Diretório onde estão as aulas e os exercicios da matéria.
